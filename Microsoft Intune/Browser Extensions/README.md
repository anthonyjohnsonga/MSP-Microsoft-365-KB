# Microsoft Intune Browser Extensions

This folder contains Microsoft Intune policy runbooks for deploying and managing browser extensions on enrolled devices.

---

### [Deploy the Bitwarden Extension to Microsoft Edge](./Bitwarden%20Edge%20Extension%20Deployment%20Runbook.md)

User-scoped Settings Catalog deployment for silently installing the official Bitwarden Password Manager extension, preventing removal, forcing its toolbar icon to remain visible, validating the resulting Edge policies, and rolling back the assignment.
